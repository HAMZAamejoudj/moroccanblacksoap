# Moroccan Black Soap (B2B)

Next.js site for Moroccan black soap wholesale, private label, and export — EN / FR / AR.

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```
